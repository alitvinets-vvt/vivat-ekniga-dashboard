# Vivat × «єКнига» — дашборд

Інтерактивний аналіз участі видавництва Vivat у державній програмі «єКнига»
за даними Українського інституту книги (1–3 кв. 2026) і залишків сайту vivat.com.ua.

## Що всередині

- **Огляд** — динаміка програми, частки видавництв, структура ТОП-300.
- **Новинки vs бекліст** — когорти за роком першого видання, віддача новинок 2025.
- **Жанри** — 17 субжанрів, місце Vivat у кожному, топ-5 тайтлів.
- **Канали і залишки** — сайти програми, покриття хітів асортиментом, перелік «докупити / додрукувати».
- **Дані** — повний ТОП-300 з фільтрами і вивантаженням у CSV.

У сайдбарі можна завантажити **нове вивантаження каталогу** (.xlsx з колонками
`ean_isbn`, `product_status`) — наявність перерахується на льоту.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой на Streamlit Community Cloud

1. Залити цей репозиторій на GitHub.
2. Зайти на [share.streamlit.io](https://share.streamlit.io) через GitHub-акаунт.
3. **New app** → обрати репозиторій, гілку `main`, файл `app.py` → **Deploy**.

## Джерела

- Зведений рейтинг УІК за 1–3 кв. 2026 (ТОП-300 книжок).
- Звіт УІК по програмі «єКнига» станом на 01.10.2026.
- Вивантаження каталогу vivat.com.ua на 06.11.2026.

Жанрова розмітка і когорти за роком першого видання — власні розрахунки, не дані УІК.
